# SKILL: Rust

## Description
Comprehensive guide to Rust 1.97.0 (Edition 2024), from syntax to async, unsafe, and project patterns.

## When to Use
- Learning Rust from scratch
- Building systems, CLI, or web tools in Rust
- Writing safe concurrent code or async applications
- Developing Rust libraries with Cargo
