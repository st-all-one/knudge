# D171 — kd sozinho = kd help

- **Status:** Aceita
- **Categoria:** Impactos no panorama (D102–D171)

## Contexto

Bloco **Impactos no panorama (D102–D171)**.

## Decisão

**`kd` sozinho = `kd help`.** Deixa de ser atalho implícito para `prime`; intenção explícita exige verbo (`prime` sempre explícito). `--json` sem verbo = `invalid_input` (2).

## Impacto

- Decisão de contrato/projeto propagada para código, testes e documentação.
